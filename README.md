# blazor-viacep-net

Aplicação Blazor que consulta endereços pelo CEP usando a API pública do [ViaCEP](https://viacep.com.br).

## Funcionalidades

- Consulta de endereço por CEP (aceita com ou sem hífen)
- Validação de CEP vazio ou com quantidade de dígitos inválida
- Tratamento de CEP não encontrado e de erros de conexão
- Exibição do resultado em tabela: CEP, logradouro, complemento, bairro, localidade, UF e DDD

## Tecnologias

- .NET
- Blazor
- Bootstrap
- API ViaCEP
